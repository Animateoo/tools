Base común

Antes de cualquier tool

Estas reglas valen para toda la suite. Léelas una vez y aplica el capítulo de cada panel.

01

CEP (.zxp)

GraphEditor, TextPresets, CompVault, MediaVault, AssetPack, Shuttle. Instala con ZXP Installer, reinicia la app y abre Window → Extensions.

02

ScriptUI (.jsx)

Mask Unlinker, Aura Pro, Audify, Cache Pro. Copia el .jsx a Scripts/ScriptUI Panels y ábrelo en Window → [Tool].

03

Demo en el sitio

En cada página hay un panel en vivo. Sirve para conocer la UI; las acciones que tocan el proyecto de AE/Pr quedan en modo demo.

04

Hosts

AE y Pr usan CEP. Ai/Ps también (Shuttle). Comprueba la versión 2022+ y que el panel aparezca tras reiniciar.
